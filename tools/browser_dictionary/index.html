How to read these results

English → Pāli uses a reverse index of Pāli–English dictionaries, not a curated English–Pāli translation dictionary. A direct gloss matches a complete English meaning (ignoring leading “a”, “an”, “the”, or “to”). A definition match only occurs within a longer explanation. Read the whole meaning: “not happy” is not a translation of “happy”. Automatically split meanings can also need context.

Pāli → English searches the original headwords. You can omit diacritics, for example “metta” for “mettā”. Exact spellings appear first; other spellings with the same letters after removing diacritics are labelled separately. Within each spelling group, DPD entries appear first in numbered sense order. Open “Diacritics” below the input to show the small character buttons. They insert diacritics or change the same letter immediately before the cursor. In partially accented queries and partial matches, matching typed diacritics rank higher within the whole-headword or partial group. Diacritics can distinguish different Pāli words, so always check the displayed headword.

Partial matching finds fragments within English definitions or Pāli headwords, starting at two characters. Whole-word or full-headword matches appear first. Within partial matches, typed Pāli diacritics take priority, followed by prefixes, then matches inside words. Partial matches are labelled: for example, “happy” can find “unhappy”, which is not an equivalent meaning. Turn off “Include partial matches” for whole-word/headword lookup only.

When no whole or enabled partial match is found, nearby spellings are suggested and the best candidate's results are shown. There may be several equally plausible suggestions. Distant spellings return no result rather than an arbitrary translation. Spelling similarity does not imply similarity in meaning.

All searching happens in your browser. No requests, accounts, APIs, or external fonts are required. See the project notes for data coverage and rebuilding.
