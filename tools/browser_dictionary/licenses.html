Provenance and changes

The input is SuttaCentral's customized lightweight export, pli2en_dpd.json. The DPD integration notes describe that earlier customization. The input JSON does not record a DPD release version or a complete history of prior export modifications. This project does not claim to include the current DPD release. Each build embeds a SHA-256 checksum of the exact input file in data.js.

  • Selected explicitly bold-marked English meanings.
  • Extracted lemma, sense number and grammar from the definition prefix.
  • Converted HTML to plain text and deduplicated inflected lookup forms into lemma senses.
  • Omitted unstructured decompositions and unmarked legacy definitions.
  • Sorted the records and indexed them for English → Pāli and Pāli → English lookup.

This is an incomplete, modified extract, not the full DPD. No endorsement by Bodhirasa Bhikkhu, DPD or SuttaCentral is implied.
