# Sutta Explorer

A separate, mobile-friendly companion to the original charts. The original
generator, charts, and embedding cache are not changed by this tool.

Build from the repository's existing 2D chart and embedding cache:

```sh
uv run --no-project --with numpy python tools/sutta_explorer/build.py
```

Open `index.html` directly in a browser. Search, collection filters, selection,
and similar blurbs work without a server or API. The optional map loads Plotly
from its CDN; fonts also use a CDN with local fallbacks.

The builder verifies that chart IDs match cached embedding IDs and computes
12 nearest neighbors using cosine similarity in the original embedding space.
These are similarities between English blurbs, not verified doctrinal relations
or textual parallels. Map positions come from the existing t-SNE projection;
their distances and cluster sizes are not quantitative similarity measures.
Cluster numbers are the original algorithm's labels, not curated topics.

Rebuild after updating the original chart and embeddings. The explorer is not
automatically regenerated by `cluster_suttas.py`.
